Fire behaves differently in space. Run the experiments yourself.

Twenty NASA fire experiments from orbit, rebuilt as labs you can play with. Light the flame, change the air, and see where each result keeps a crew safe.

    Results come from NASA's Physical Sciences Informatics database. Each lab runs a simplified model, checked against those results where a table exists; the Result tab in every lab says how far to trust it.
